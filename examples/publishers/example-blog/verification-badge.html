WordPress Implementation

// Add to footer.php
<?php if (function_exists('aiindex_verified_badge')): ?>
    <div class="footer-badge">
        <?php aiindex_verified_badge(); ?>
    </div>
<?php endif; ?>

// Or use shortcode
[aiindex_badge size="medium"]

Styling Tips

.aiindex-badge {
    display: inline-block;
    margin: 10px 0;
    transition: transform 0.2s;
}

.aiindex-badge:hover {
    transform: scale(1.05);
}

/* Footer placement */
.site-footer .aiindex-badge {
    margin-top: 20px;
}

/* Sidebar widget */
.widget-aiindex .aiindex-badge {
    text-align: center;
    display: block;
}

Verification Status

When clicked, the badge links to your publisher profile at:

https://aiindex.org/publishers/example-blog.com

  • Verification status and date
  • Publisher information
  • Access policy
  • Receipt statistics (if public)
  • ai-index.json download link
