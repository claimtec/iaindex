## 🔄 Migration Path

### Backward Compatibility
- ✅ **100% backward compatible** - v1.0 files work unchanged
- ✅ **No breaking changes** - existing integrations continue to work
- ✅ **Graceful degradation** - v1.1 clients work with v1.0 publishers
- ✅ **Version negotiation** - automatic fallback to supported version

### Migration Process (15-25 minutes)
```bash
# 1. Backup database (5 min)
pg_dump iaindex_db > backup.sql

# 2. Run database migration (2-5 min)
psql aiindex_db < migrations/v1.0-to-v1.1.sql

# 3. Migrate AI Index files (1-2 min)
python3 migrations/migrate-ai-index.py /publishers --recursive

# 4. Generate policy files (30 sec)
python3 migrations/generate-well-known.py /publishers --recursive

# 5. Test (5-10 min)
cd tests/e2e && pytest -v

# 6. Deploy updated API and dashboard
# 7. Update plugins (optional, backward compatible)
```
