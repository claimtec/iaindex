# AIIndex v1.1 Quick Reference

## What Was Added to Each Plugin

### 1. WordPress Plugin (`/packages/wp-plugin/`)

#### Files Modified:
1. `admin/admin-settings.php` - Added Policy Controls tab, enhanced Verification and Analytics tabs
2. `includes/class-generator.php` - Updated to v1.1 JSON format with policy methods
3. `public/badge-shortcode.php` - Added verification display support
4. `admin/assets/admin.css` - Added toggle switches and verification card styles

#### Key Code Additions:

**Policy Tab:**
```php
<a href="?page=aiindex&tab=policies" class="nav-tab">Policy Controls</a>

<label class="aiindex-toggle">
    <input type="checkbox" name="aiindex_block_training" />
    <span class="aiindex-toggle-slider"></span>
</label>
```

**Generator v1.1:**
```php
'version' => '1.1',
'policy' => $this->get_policy_settings(),
'receipts' => $this->get_receipt_settings(),
'render_fallback' => $this->get_render_fallback_settings()
```

**Badge Shortcode:**
```php
'show_verification' => 'false' // NEW attribute
[aiindex_badge show_verification="true"]
```

## Generated JSON Structure

### ai-index.json (v1.1)
```json
{
  "version": "1.1",
  "policy": {
    "training": "block",
    "retrieval": "allow"
  },
  "receipts": {
    "require_signed": true
  },
  "render_fallback": {
    "mode": "edge",
    "enabled": true
  }
}
```

### .well-known/aiindex-policy.json
```json
{
  "version": "1.1",
  "domain": "example.com",
  "policy": { "training": "block" },
  "receipts": { "require_signed": true },
  "render_fallback": { "mode": "edge", "enabled": true }
}
```

## Quick Usage

### WordPress
```bash
1. WP Admin > AIIndex > Policy Controls
2. Toggle policies
3. Save
4. Use shortcode: [aiindex_badge show_verification="true"]
```

### Shopify
```bash
1. Apps > AI Index
2. Policy Controls tab
3. Toggle policies
4. Save Policy Settings
5. View Verification tab
```

### Others
```bash
1. Open policy-config-v1.1.html
2. Configure policies
3. Copy embed code
4. Add to platform's custom code section
```
