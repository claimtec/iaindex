MAIN FEATURES
================================================================================

1. AUTO-GENERATION OF AI-INDEX.JSON
   ✓ Automatic generation from WordPress posts/pages
   ✓ Served at /ai-index.json with proper headers
   ✓ Includes content, metadata, categories, tags
   ✓ Real-time generation on each request

2. CRYPTOGRAPHIC SIGNING
   ✓ Ed25519 key pair generation
   ✓ Automatic content signing
   ✓ Public key distribution
   ✓ Verification support

3. RECEIPT MANAGEMENT
   ✓ REST API endpoint: /wp-json/aiindex/v1/receipt
   ✓ Custom database table for receipts
   ✓ Receipt validation and storage
   ✓ Analytics and reporting

4. ADMIN INTERFACE
   ✓ Settings page with 4 tabs (General, Keys, Verification, Analytics)

   ✓ Dashboard widget with quick stats

   ✓ WordPress Cron scheduled sync

   Icon: dashicons-networking

REST API ENDPOINTS
================================================================================

1. POST /wp-json/aiindex/v1/receipt
   Purpose: Receive indexing receipts
   Access: Public
   Authentication: None required
   
2. GET /wp-json/aiindex/v1/receipts
   Purpose: List all receipts
   Access: Admin only
   Authentication: WordPress auth required
   
3. GET /wp-json/aiindex/v1/index
   Purpose: Get current index
   Access: Public
   Authentication: None required

================================================================================
DATABASE TABLES
================================================================================

Table: wp_aiindex_receipts

Columns:
- id (bigint) - Primary key
- receipt_id (varchar) - Unique receipt identifier
- content_url (text) - URL of indexed content
- content_hash (varchar) - SHA-256 hash
- indexed_at (datetime) - Indexing timestamp
- indexer_name (varchar) - Indexer name
- indexer_url (text) - Indexer URL
- verification_status (varchar) - Status
- metadata (longtext) - JSON metadata
- created_at (datetime) - Creation timestamp

Indexes:
- PRIMARY KEY (id)
- UNIQUE KEY (receipt_id)
- KEY (content_hash)
- KEY (indexed_at)

================================================================================
INSTALLATION INSTRUCTIONS
================================================================================

Quick Install:
1. Copy wp-plugin folder to WordPress plugins directory
2. Rename to 'aiindex'
3. Activate in WordPress admin
4. Configure settings

Using Install Script:
./install.sh /path/to/wordpress

Manual Installation:
cp -r wp-plugin /path/to/wordpress/wp-content/plugins/aiindex
chmod -R 755 /path/to/wordpress/wp-content/plugins/aiindex
