Your AI Index URL

This URL will serve your AI Index JSON:

https://yoursite.com/ai-index.json
Note: Squarespace doesn't support custom API endpoints, so the AI Index is served via JavaScript and localStorage. For best results, ensure the main script is loaded in your header.
