Installation

Add this code to your Webflow site's Custom Code section (Site Settings > Custom Code > Footer Code):

<script src="https://cdn.aiindex.org/webflow/snippet.js"></script> <script> window.aiIndexConfig = { apiKey: 'YOUR_API_KEY', domain: 'your-domain.com', webhookUrl: 'https://your-site.com/webhook', badgeEnabled: true, autoSync: true }; AIIndexWebflow.init(window.aiIndexConfig); </script>
