## /developers

### Developers: Build with Consent

Integrate AIIndex into your AI application in under 10 minutes. Respect publisher policies automatically, send cryptographic receipts, and access render fallback when needed.

**Quick Start**:
```bash
npm install @aiindex/sdk
# or
pip install aiindex-sdk
```

**Features**: Policy discovery via `/.well-known/aiindex-policy.json` • Automatic receipt signing • 403 Forbidden handling with denial receipts • Render fallback for dynamic content • Rate limiting with exponential backoff

**Frameworks Supported**: LangChain, LlamaIndex, custom implementations

[View API Docs →](https://docs.aiindex.org)
